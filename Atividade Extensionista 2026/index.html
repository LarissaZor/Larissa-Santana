Programação em poucas palavras
Programação: Dá instruções para o computador realizar uma tarefa.
Algoritmo: Sequência de passos para resolver um problema.
Código: As instruções escritas para o computador.
Variável: Um espaço onde guardamos uma

Decisão (if / else)
Imagine um semáforo:se
estiver verde, atravessa;
se caso for
vermelho, você espera.
O programatoma decisões
dependendo de uma condição.

Repetição (Loop)
Imagine que você precisa
varrer a sala.
Enquanto tiver sujeira
continua varrendo.
Se caso nao houver mais,
para. O loop repete uma
ação enquanto determinada
condição for verdadeira.
